# 🏦 FortressFinance — Banking Management System

**FortressFinance** is a backend-focused Banking Management System that simulates real-world banking operations such as customer management, transactions, and secure data handling.

## 🚀 Features
- Account creation
- Deposit & withdrawal
- Balance enquiry
- Transaction handling
- Database-backed persistence

## 🛠 Tech Stack
- Java
- MySQL
- Git & GitHub
